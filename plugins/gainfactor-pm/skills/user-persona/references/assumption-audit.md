# 假设与画像审查

用户要求详细假设管理时，使用下表：

| 假设 ID | 画像假设 | 来源 | 重要性 | 不确定性 | 错误影响 | 验证优先级 |
|---|---|---|---:|---:|---|---|

优先登记会改变分类、群体边界、Persona 核心行为或路线图优先级的假设。

检查：

- 分类是否具有不同 JTBD、场景或行为模式，是否大量重叠；
- 群体画像与 Persona 是否一致；
- 当前行为能否解释痛点和产品反应；
- 每条关键判断是否能回到 Agent 原始反馈或用户材料，归纳与原始表达是否分开；
- 是否出现没有证据支持的用户比例、群体规模或精确属性。
