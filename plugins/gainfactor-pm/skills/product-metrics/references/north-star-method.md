# 北极星指标方法

仅在任务为“长期产品指标体系”时读取。本文件用于定义产品级北极星，不适用于上线、专项优化或单次实验的主要指标。

## 定义

北极星指标是在自然使用周期内，产品向核心用户持续交付合格价值单元的唯一产品级度量。它应领先于可持续商业或组织结果，并能被产品团队通过多个合理杠杆持续影响。

```text
在【自然周期】内，【合格统计主体】通过产品成功完成【价值事件】，
并满足【质量或有效条件】的【去重数量／比例／总量】。
```

## 推导顺序

1. **产品价值承诺**：写清谁在什么场景下，通过产品获得什么有效结果。
2. **价值单元**：找到产品成功交付一次核心价值时，现实中发生的最小可观察事件。
3. **合格条件**：规定成功、采纳、质量、履约或有效性条件，并排除取消、失败、作弊、测试和低质量结果。
4. **统计主体**：确定价值由用户、账户、团队、任务、交易、内容或多边交换事件承载。
5. **自然周期**：按照真实价值发生频率选择日、周、月、任务周期或其他窗口，不按报表习惯机械选择。
6. **长期结果假设**：解释持续增加合格价值单元为什么会领先于留存、复购、续约、收入、网络效应或组织成果。
7. **形成候选**：生成 2–3 个候选并完成最小测量契约。
8. **门禁评估**：通过价值、战略、测量、健壮性和证据门禁后推荐唯一候选。

点击、访问、注册、创建、生成、发送和单纯在线通常只是前置行为。收入、ARR 和 GMV 通常是经营结果。只有它们本身满足价值实现与其他门禁时，才可能成为产品北极星。

## 多边产品

优先寻找关键参与方共同完成的一次价值交换，例如有效完成的交易、履约或匹配。北极星不必表达每一方的全部收益；供需平衡、收益公平、质量和信任使用平衡或底线指标保护。

不要为了“所有人都成功”构造难以解释的加权评分。只有不存在可解释的原子价值单元时才考虑复合指标，并公开组成、权重、归一化和失真风险。

## 相似产品研究

相似产品研究只用于校准候选。价值单元或战略关系没有实质疑问时可以不检索；需要时最多研究 3–5 个真正相似的产品，不凑数。

| 标签 | 能得出的结论 |
|---|---|
| 官方明确称为北极星 | 证明对方这样管理，不证明适合当前产品 |
| 官方关键业务指标 | 证明对方正式使用该经营口径，不能自动称为北极星 |
| 官方产品／实验指标 | 可参考其如何定义合格价值 |
| 分析推断 | 只能生成候选，不能写成对方事实 |
| 行业传闻 | 不进入事实依据或最终选择理由 |

只提取会改变当前候选的价值单元、资格条件、统计结构或风险，不把完整研究过程写入门户。

## 常见误用

| 指标形态 | 默认角色 | 成为北极星候选的前提 |
|---|---|---|
| DAU／MAU、访问人数 | 规模或参与度 | “活跃”具有严格价值条件，而非任意访问 |
| 消息、生成、创建、实验数量 | 过程或产出量 | 结果通过采纳、履约、质量或决策有效性条件 |
| 收入、ARR、GMV | 财务或经营结果 | 与核心价值高度同构且主要混杂因素可控 |
| 早期行为次数或门槛 | 激活或留存预测 | 对全部核心用户长期成立，且行为就是价值实现 |
| 完成的交易、任务或履约 | 较强价值候选 | 完成条件真实、质量可控并保护多边利益 |

“容易统计”和“与留存相关”都不能单独证明一个指标是北极星。

## 五层门禁

使用 `✅`、`⚠️`、`❌`，只展示影响选择的依据。

### A. 价值

- 是否度量用户已经获得的核心价值，而非前置动作？
- 想提高它时，是否必须创造更多真实用户价值？
- 是否有明确合格和排除条件？
- 是否覆盖核心用户和多边价值交换？
- 是否可追溯到 `PRODUCT_DEFINITION`？

### B. 战略

- 是否是唯一产品级长期指标？
- 是否领先于可持续商业或组织结果？
- 产品团队是否能通过多个合理杠杆影响？
- 产品价值主张不变时是否相对稳定？

### C. 测量

- 最小测量契约是否完整？
- 是否至少有条件可统计、可衡量？
- 是否能及时识别有意义的产品变化？
- 是否能按关键用户、场景或风险群体拆分？

### D. 健壮性

- 是否能在没有增加真实价值时被刷高？
- 是否主要受流量、价格、促销、库存或季节影响？
- 是否有质量、信任、成本和多边平衡底线？
- 是否可解释、可行动，避免不透明复合评分？

### E. 证据

成熟产品在数据可得时检查：

- 指标较高的主体是否更容易后续留存、复购、续约或获得组织成果；
- 指标是否领先于长期结果，而非仅同期相关；
- 关系是否在关键群体和时间段相对稳定；
- 产品改进是否曾推动指标且未击穿底线；
- 样本、窗口、口径、来源和证据日期是否明确。

新产品或缺少历史数据时标记 `待验证`，定义验证假设、窗口、样本需求和晋级条件；相似产品不能代替本产品证据。

## 裁决

- 价值实现、完整口径、可统计性或可衡量性为 `❌`：候选不通过。
- 长期关系、抗博弈或副作用控制为 `❌`：不得确认为北极星。
- 定义通过但证据不足：`Definition Status: confirmed`，`Measurement Readiness: unverified` 或 `partially-ready`。
- 修正后仍无候选通过：标记 `待定义`，不伪造最终答案。
